# README

## Tech stack

| Warstwa        | Technologie    |
| -------------- | -------------- |
| Backend        | PHP 8.3        |
| Serwer HTTP    | Nginx          |
| Konteneryzacja | Docker Compose |

## Szybki start

```bash
git clone https://github.com/vodfsh/PK-WDPAI.git
cd PD-WDPAI
docker compose up --build -d
docker compose exec php composer install
```

Aplikacja: <http://localhost:8080>
